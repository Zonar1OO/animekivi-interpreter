# ПееревводчикKivi для Android — версия 0.3 (исходный проект)

Языки: ан6глийский, немецкий, корейский, китайский (упрощённый) → русский.

## Функции проекта
- выбор исходного языка;
- распознавание речи через системную службу Android;
- перевод через ML Kit Translation (модель загружается при первом использовании);
- русская озвучка через TextToSpeech;
- заготовка плавающей плашки субтитров поверх других приложений, включая TikTok (нужно разрешение Android).

## Сборка APK
Это **исходный код, не готовый и не протестированный APK**. В среде подготовки нет Android SDK/Gradle для сборки.
1. Откройте папку проекта в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Выберите Build → Build APK(s).
4. APK обычно создаётся в `app/build/outputs/apk/debug/app-debug.apk`.

## Важные ограничения
- Первая версия слушает речь через микрофон, не напрямую из TikTok. Для эфира используйте громкую связь.
- Android/TikTok могут запрещать внутренний захват звука другими приложениями.
- Субтитры появляются в плавающей плашке только после предоставления разрешения «Показывать поверх других приложений» и включения её кнопкой.
- Распознавание использует системный сервис Android, доступность языков/офлайн-режима зависит от устройства и настроек.
- Это прототип: задержки и ошибки распознавания возможны. Проверьте на своём устройстве перед использованием.

Package: `com.animekivi.livetranslate`


## Версия 0.4 — автоопределение языка

- Добавлен пункт «Автоопределение языка»: язык распознанной фразы определяется автоматически, затем выбирается перевод на русский.
- Список доступных языков в ручном режиме формируется из языков, поддерживаемых ML Kit Translate.
- Для автоматического распознавания языка речи используются возможности системной службы распознавания Android, если она их поддерживает. На Android ниже 14 и на некоторых устройствах автоопределение речи может не работать; в таком случае выберите язык вручную.
- «Любой язык» не гарантируется: поддержка зависит от распознавания речи Android и доступности модели перевода ML Kit для конкретного языка. Первый запуск языковой модели требует интернета.
- Для эфира TikTok используется микрофон телефона; приложение не гарантирует прямой захват внутреннего звука TikTok. Чтобы субтитры показывались поверх эфира, нужно разрешить отображение поверх других приложений.

Это исходный проект, не готовый APK. Его нужно собрать в Android-среде; на реальном телефоне требуется проверка.


## Облачная сборка APK без Android Studio

В проект добавлен GitHub Actions workflow `.github/workflows/build-apk.yml`. После загрузки папки проекта в новый репозиторий GitHub:

1. Откройте репозиторий на GitHub и перейдите во вкладку **Actions**.
2. Выберите **Build ПереводчикKivi APK** и нажмите **Run workflow** (либо дождитесь сборки после отправки файлов в `main`).
3. Откройте завершённый запуск workflow. Внизу раздела **Artifacts** скачайте `PerevodchikKivi-debug-apk`.
4. Распакуйте скачанный архив на телефоне и установите `app-debug.apk`. Если Android спросит, разрешите установку из этого источника.

Это автоматизирует сборку в облаке, но APK появится только после успешного запуска workflow. Сборка и работа на реальном телефоне заранее не подтверждены.
